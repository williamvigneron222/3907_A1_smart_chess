# 3907_A1_smart_chess

## Overview
This project was done for ELEC3907. The goal was to build a system that can support secure communication using 
different embedded subsystems. These include key generation, communication, cryptography, and some hardware 
interfaces like IR and LCD.

## Project Structure
The `FINAL_DESIGNS` folder contains the main parts of the project:

- IR:LCD → IR and LCD related files  
- ADC → analog to digital conversion  
- communication → handles sending data between devices  
- crypto → encryption-related code  
- keygen → random key generation  

There are also some extra folders for testing and other work.
